
# XKanFuse
This is official Pytorch implementation of ["XKanFuse: A Novel Cross-Modal Fusion Method based on Kolmogorov-Arnold Network for Multi-Modal Medical Image Fusion"](https://ieeexplore.ieee.org/document/9812535)

The pretrain model is avaiable at https://drive.google.com/file/d/10ZuyZcCk3SHeee_vc4yBX67BHG3EnVhL/view?usp=drive_link
